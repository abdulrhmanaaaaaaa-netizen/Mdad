# مِداد | MIDĀD Studio

منصة عربية للإبداع والكتابة والبحوث، تعمل بواجهة HTML وCSS وJavaScript عادي، وخادم Node.js بوحداته المدمجة فقط. لا تحتاج إلى React أو Vue أو axios أو أي مكتبات npm أو CDN أو خطوط خارجية.

## ما الذي تفعله النسخة؟

- شخصية مِداد الحوارية مضمّنة في `persona.js` وتضاف تعليماتها إلى كل طلب.
- رِيشة هي الرفيق المرئي لمِداد وتظهر في الواجهة والمحادثات.
- المحادثات تحفظ محليًا في المتصفح.
- إنشاء مشروع قصة/رواية من **العنوان والوصف**: يطلب مِداد من DeepSeek ملخصًا، وشخصيات، وعالمًا، ومخطط فصول، وافتتاحية قصصية.
- إنشاء مشروع بحث من **العنوان والوصف**: يطلب مِداد سؤالًا بحثيًا، وخطة ومحاور، ومصادر عند توافر معلومات موثوقة، ومسودة بحث منظمة.
- يظهر تقدم الإنشاء، وتُحفظ بيانات المشروع محليًا، وتوجد إعادة محاولة عند فشل الخدمة.
- محرر للمشروع يحفظ الملخص والشخصيات والعالم والخطة والمصادر والنص تلقائيًا.
- مكتبة للمشاريع والمحادثات والمستندات، مع مظهر داكن Deep Olive ومظهر فاتح Soft Sage.
- ألوان الهوية مأخوذة من الصورة المرجعية: `#ABC8A3` (Soft Sage) و`#1A2519` (Deep Olive).

## تشغيل الموقع

يتطلب Node.js 18 أو أحدث. لا تحتاج إلى `npm install` أو تثبيت أي حزم.

```bash
node server.js
```

ثم افتح:

```text
http://localhost:3000
```

## ربط DeepSeek الذي أرسلته

استخدم الخادم نفس تسلسل كود الإضافة المرسل، وليس نقطة الاتصال الداخلية `chat.deepseek.com`:

1. يرسل الخادم طلب GET إلى `https://deep-seek.ai/chat`، ويستخرج قيمة `csrf-token` من HTML.
2. يرسل طلب POST إلى `https://deep-seek.ai/api/chat`.
3. يرسل الرؤوس `X-CSRF-TOKEN` و`Origin` و`Referer` و`User-Agent`، كما في كودك.
4. يستخدم النموذج `deepseek/deepseek-v4-flash` ورسائل `messages`.
5. يقرأ رد SSE ويجمع `choices[0].delta.content`.

كل ذلك داخل `server.js` باستخدام `fetch` المدمج في Node.js. لا تُرسل رموز أو مفاتيح من المتصفح، ولا توجد مكتبة Axios.

المسارات المحلية:

- `POST /api/chat` للمحادثات.
- `POST /api/generate-project` لإنشاء القصص والبحوث آليًا من العنوان والوصف.
- `GET /api/status` يعرض معلومات إعداد محلية فقط ولا يرسل اختبارًا إلى مزود الخدمة.

**مهم:** لم أرسل طلبًا تجريبيًا إلى DeepSeek؛ لذلك لم أتحقق من الاستجابة الفعلية لهذا الخادم. كود الاتصال مطابق لتسلسل الإضافة الذي قدمته، لكن قبول الموقع للطلبات يظل تابعًا لحالته وسياساته وتغييرات الحماية لديه. كما أن توثيق المصادر في البحث لا يُختلق: إذا لم يستطع النموذج التحقق من مصدر، يطلب استكمال التوثيق بدل اختراع مرجع.

## النشر

هذه المنصة تحتاج خادم Node.js لأن اتصال DeepSeek يتم من الخادم. لا يكفي رفع الملفات إلى GitHub Pages وحده؛ ارفع المجلد إلى استضافة تدعم Node.js ثم شغّل `node server.js`. لا توجد متغيرات سرية أو ملفات `.env` مطلوبة في هذا الربط.

## الملفات

- `index.html`: بنية الموقع.
- `styles.css`: التصميم والثيمات والحركات.
- `app.js`: الواجهة والتخزين المحلي وإنشاء المشاريع.
- `persona.js`: شخصية مِداد وقواعدها وأنماطها.
- `server.js`: خادم الويب وربط DeepSeek.
- `assets/`: صور رِيشة المحلية.
