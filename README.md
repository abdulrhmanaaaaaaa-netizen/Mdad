# مِداد | MIDĀD Studio

منصة عربية للكتابة الإبداعية والبحوث والمحادثة الذكية. الواجهة مبنية بـ HTML وCSS وJavaScript عادي دون أطر عمل أو مكتبات خارجية أو خطوط محمّلة من الإنترنت. الخادم يستخدم وحدات Node.js المدمجة فقط. لا توجد أي حزم npm مطلوبة.

## المزايا الموجودة

- شخصية مِداد وتعليماتها موجودة في `persona.js`، ويحقنها الخادم في كل طلب وفق نمط المحادثة.
- أنماط للمساعد العام والكتابة الروائية والبحث والتحرير.
- محادثات ومشاريع قصص وبحوث ومستندات.
- دليل رواية يحفظ الملخص والشخصيات والعالم ومخطط الفصول.
- مساحة بحث تحفظ السؤال والخطة والمصادر المدخلة والمسودة.
- محرر مستندات مع حفظ تلقائي محلي.
- مكتبة وقوالب ومظهر داكن وفاتح.
- البيانات المحفوظة من الواجهة تبقى في Local Storage على الجهاز الحالي.
- اتصال DeepSeek يتم من `server.js` حتى لا تُرسل بيانات الجلسة إلى المتصفح.

## التشغيل

يتطلب Node.js 18 أو أحدث (لأن الخادم يستخدم `fetch` المدمج).

```bash
node server.js
```

ثم افتح `http://localhost:3000` في المتصفح.

لا تستخدم `npm install` ولا تحتاج إلى أي حزم خارجية. جميع الخطوط من خطوط النظام المثبتة على جهاز المستخدم، وجميع ملفات الواجهة محلية.

## الاعتماديات والخطوط

- لا توجد React أو Vue أو jQuery أو Bootstrap أو Tailwind أو أي مكتبات JavaScript خارجية.
- لا توجد CDN أو مكتبات أيقونات أو ملفات خطوط خارجية.
- الأيقونات والعناصر المرئية مرسومة بعناصر HTML وCSS ورموز نصية داخل المشروع.
- ملفات الواجهة: `index.html` و`styles.css` و`app.js` و`persona.js`.
- الخادم: `server.js`، ويستخدم وحدات Node.js الأساسية (`http` و`fs` و`path`) وواجهة `fetch` المدمجة في Node.js 18 أو أحدث.

## إعداد DeepSeek

إعدادات الاتصال موجودة في ملف `.env` على الخادم. ستجد ملف إعدادات الجلسة منفصلًا باسم `midad-deepseek.env`؛ ضعه بجوار `server.js` وأعد تسميته إلى `.env`. لا تضع هذه القيم في `app.js` أو `index.html` أو أي ملف يصل إلى المتصفح.

نقطة الاتصال المستخدمة هي نفس المسار الداخلي الذي حدده صاحب المشروع:

`https://chat.deepseek.com/api/v0/chat/completion`

يستخدم الخادم رؤوس الجلسة ومعرّف المحادثة وحقول الطلب المرسلة في طلب cURL، ويضيف تعليمات شخصية مِداد وسياق المحادثة إلى حقل `prompt`.

**تنبيه:** هذه واجهة داخلية لموقع DeepSeek وليست API عامة موثقة للمطورين. قيم الجلسة قد تكون مؤقتة أو مرتبطة بالجهاز والمحادثة. لم يتم إرسال أي طلب اختبار إلى DeepSeek وفق طلب صاحب المشروع؛ لذلك لم يتم التحقق من قبول الخدمة للطلب أو استمرار صلاحية بيانات الجلسة.

## النشر

لا يكفي رفع هذه الملفات إلى GitHub Pages وحده؛ لأن GitHub Pages لا يشغّل `server.js`. يجب نشر المجلد على استضافة تدعم Node.js وتشغيل `node server.js`، أو وضع الواجهة على استضافة ثابتة والخادم على خدمة Node منفصلة مع تعديل مسار `/api/chat`.

## حماية الجلسة

ملف `.env` يحتوي على بيانات الجلسة التي أُرسلت أثناء إعداد المشروع، وهو مستثنى في `.gitignore` وغير موجود داخل حزمة الموقع العامة. حمّل ملف `midad-deepseek.env` المنفصل، وانقله إلى خادم Node فقط وأعد تسميته إلى `.env`. لا ترفعه إلى GitHub ولا تشاركه. إذا كان المستودع عامًا، ارفع ملفات المشروع الأخرى فقط، ثم أضف متغيرات البيئة من لوحة الاستضافة الخاصة بالخادم. وبما أن بيانات الجلسة ظهرت في المحادثة، فمن الأفضل إنهاء تلك الجلسة أو تجديدها قبل نشر الموقع علنًا.

## الشخصية المرئية: رِيشة

أُضيفت إلى مِداد شخصية مرئية أصلية باسم **رِيشة**: رفيق صغير بعباءة حبرية ووجه مضيء، يحمل ريشة كتابة وكتابًا. تظهر في الصفحة الرئيسية، ورأس المحادثة، ورسائل المساعد، وبطاقة جانبية. لها حضور بصري لطيف وحركة عائمة هادئة، بينما تبقى هوية المساعد الحوارية هي مِداد.

ملفات الرسم محلية داخل `assets/` ولا تعتمد على CDN أو مكتبات أو خدمات صور خارجية.
